# Portfolio Website

A single-page web portfolio for myself.
Built using modern web technologies, it combines performance, scalability, and responsiveness.

## Tech Stack
- React & Next.js: Leveraging the App Router and Server Actions for a seamless user experience.
- TypeScript: Ensuring type safety and maintainability.
- Tailwind CSS: For rapid and flexible styling.
- Framer Motion: Adding smooth animations and interactions.
- AWS Hosting:
  - Route 53: Domain management.
  - CloudFront: Content delivery and caching.
  - Amplify: Continuous deployment and hosting.
